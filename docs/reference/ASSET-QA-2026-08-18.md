## Traçabilité

`apps/client/public/img/manifeste.json` porte pour chaque image :

- clef et chemin exacts ;
- dimensions et octets réels ;
- invite canonique de régénération ;
- identifiant de l'appel ImageGen ;
- empreinte SHA-256 du WebP final.

Limite explicite : ImageGen intégré n'expose ni graine numérique ni journal
verbatim de l'invite interactive. Le manifeste conserve donc l'identifiant de
génération dans `graine` et une invite canonique normalisée. Il ne prétend pas à
une régénération bit-à-bit impossible à prouver.

## Branchement vérifié dans le code

Confirmé :

- `apps/client/src/art/index.ts` appelle `appliquerAssetsGeneres` après le rendu
  procédural ; une image valide remplace donc une clef sans supprimer le repli ;
- les portraits sont demandés par `apps/client/src/render/heroes.ts` sous
  `portrait_<id>` ;
- les terrains sont demandés par `atlas.terrainBrush(...)`.

Encore à intégrer :

- aucun consommateur ne demande encore `accueil_paysage` ou
  `accueil_portrait` ;
- aucun consommateur ne demande encore les six clefs `cite_*` ;
- les huit `matiere_*` sont chargées dans la table générique de textures, mais
  ne remplacent pas encore les matières procédurales utilisées par les formes.

Ces trois points sont confiés à Claude Code par
`docs/reference/CLAUDE-CODE-ASSET-HANDOFF.md`. Les fichiers de carte et de combat
du lot 4 restent hors périmètre.
